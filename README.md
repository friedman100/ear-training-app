# אוזן מוזיקלית — האקדמיה לגיטרה

אפליקציית Web בעברית וב־RTL לתרגול מרווחים מלודיים עולים, עם פסנתר בלבד. ללא שרת, הרשמה או תשלום.

## לפתוח ולהתחיל לתרגל

הדרך הפשוטה: פתחו את `ear-training.html` שנוצר באמצעות `npm run standalone` מתוך תיקיית `dist`, בדפדפן Chrome, Edge, Firefox או Safari. כל דגימות הפסנתר כלולות בקובץ. לחצו על **האזנה למרווח** ואפשרו צליל במכשיר. השמעה מתחילה רק בלחיצה, בהתאם לכללי הדפדפנים.

בטלפון מומלץ לפתוח את הגרסה המתארחת באתר HTTPS. פתיחת קובצי HTML מקומיים בטלפון משתנה בין דפדפנים. בחלון גלישה פרטי ההתקדמות עשויה להימחק בסגירתו.

## הרצה לפיתוח / תצוגה מקדימה

נדרש Node.js 20.19 ומעלה או 22.12 ומעלה.

```sh
npm ci
npm run dev
```

פתחו את הכתובת שמופיעה במסוף (בדרך כלל `http://localhost:5173`). בסביבה מרוחקת פתחו תצוגה מקדימה לפורט 5173; localhost של הסביבה אינו ה־localhost של המחשב שלכם.

```sh
npm test
npm run test:ui
npm run build
npm run standalone
```

`dist` מתאים לכל שירות אחסון סטטי. אין צורך במסד נתונים או במפתחות API. ההתקדמות נשמרת בדפדפן ובכתובת שבה מתרגלים; מעבר בין דומיינים/דפדפנים או ניקוי נתוני האתר אינם מעבירים את ההתקדמות.

## כללי התרגול

- גוף הצליל נמשך 0.8 שניות, עם זנב דעיכה מעריכית של 1.4 שניות. התו השני מתחיל לאחר 0.85 שניות, כך שזנב הראשון חופף לו בעדינות עד לשקט. תווים מקוריים בדגימות פסנתר Salamander Grand Piano V3 (שכבת נגינה עדינה 4 מתוך 16), בכיוון שווה־מזג A4=440Hz. פרטי רישוי ב־`public/audio/LICENSE.md`.
- מנעדים: נמוך C3–C5, אמצעי C4–C6, גבוה C5–C7. שני הצלילים תמיד בתוך המנעד.
- תשובה שגויה מסומנת באדום בלבד. אפשר לנסות עד שמצליחים; אין מעבר אוטומטי.
- רק התשובה הראשונה לשאלה נרשמת במדדים. טעויות נוספות והאזנות אינן משנות אותם.
- חלון ההתקדמות הוא `max(20, 4 × מספר המרווחים הפעילים)` שאלות. נדרשים 80% הצלחה לפחות ולפחות שתי הופעות לכל מרווח. הבחירה מאזנת את מספר הופעות המרווחים, עם צליל התחלה אקראי בכל שאלה. החלון מתאפס בפתיחת שלב.
- חלק א׳ מסתיים בסקונדה קטנה. המעבר לחלק ב׳ נעשה רק בלחיצה.
- מסלול מודרך ומצב חופשי שומרים מדדים נפרדים. הגדרות המנעד משותפות.
- שאלת התרגול הנוכחית, כולל מספר הניסיונות, נשמרת בטעינה מחדש. יש ללחוץ שוב על האזנה לאחר רענון לפני בחירת תשובה.

## מבנה הקוד

- `src/logic.js`: מרווחים, מנעדים, שאלות, בדיקת תשובות, פתיחת שלבים וטעינת התקדמות.
- `src/audio.js`: טעינת דגימות ותזמון Web Audio.
- `src/main.js`: ממשק וניהול התרגול.
- `src/style.css`: עיצוב רספונסיבי.
- `tests`: בדיקות לוגיקה ואינטראקציה בממשק.
- `scripts/standalone.mjs`: אריזת האפליקציה לקובץ HTML עצמאי.

בדיקות הממשק רצות בסביבת DOM מדומה; הן אינן מחליפות בדיקת האזנה פיזית או בדיקה בדפדפן ובטלפון אמיתיים.

## סיום תרגול וסיכום אישי

לחצו על **סיום תרגול** בחלק העליון של כרטיס התרגול. הסיכום מתייחס לתרגול הנוכחי בשני המצבים יחד, וסופר רק שאלות שהושלמו בהצלחה — כל שאלה פעם אחת. טעות ואחריה תיקון נכללים בשאלה שהושלמה, אך אינם הצלחה בניסיון הראשון. האזנות ושאלות שלא הושלמו אינן נספרות בסיכום.

הסיכום כולל מספר שאלות שהושלמו, אחוז הצלחה בניסיון הראשון, רצף מרבי, פירוט הצלחות מתוך שאלות לכל מרווח ומרווחים שנפתחו במסלול המודרך. **תרגול חדש** מאפס רק את נתוני התרגול הנוכחי. אין סיום אוטומטי או מגבלת שאלות.

נתוני התרגול נשמרים במפתח נפרד `ear-training-session-v1`, לצד ההתקדמות הקיימת ב־`ear-training-v1`. רענון משחזר גם סיכום שכבר נפתח. לא נשמרת היסטוריית תרגולים.

## השוואת פסנתרים לפני החלפת מקור הצליל

`demo/piano-comparison.html` הוא קובץ עצמאי להשוואת FluidR3 הקיים מול Salamander Grand Piano V3 בשכבת נגינה עדינה (4 מתוך 16). הורידו ופתחו בדפדפן, בחרו אזור ומרווח ולחצו על כל אחד משני הפסנתרים. אין שינוי בצליל התרגול ואין שימוש בנתוני ההתקדמות.

הקובץ כולל 16 תווים בכל מקור, 5 מרווחים ושלושה אזורי מקלדת. עוצמת המקורות מאוזנת בקירוב לצורך ההשוואה; אין זו מדידת שוויון עוצמה תפיסתית. שני המקורות קוצרו ל־0.8 שניות עם 15ms התחלה רכה ו־300ms דעיכה; נשמרת הפסקה של 50ms בין התווים. לא נעשה שימוש בצלילים של Toned Ear.

- `npm run comparison`: אריזת ההשוואה העצמאית מתוך הקבצים הקיימים.
- `npm run test:comparison`: בדיקת הקובץ העצמאי, כל אפשרויות ההשמעה, חזרה ושמירת נתוני התרגול ללא שינוי.
- `scripts/prepare-piano-comparison.py`: שחזור קובצי ההשוואה. נדרש ffmpeg וחילוץ `audio` מחבילת `@audio-samples/piano-velocity4@1.0.5` לתוך `work/piano-comparison/source`. אין צורך להתקין זאת כדי להשתמש בקובץ המוכן.
- פרטי המקור, הרישוי והעיבוד: `public/piano-comparison/LICENSE.md`.

## הפסנתר שנבחר לתרגול

לאחר השוואת האזנה נבחר Salamander Grand Piano V3, בשכבת נגינה עדינה 4.
כל 49 התווים C3–C7 כלולים מקומית. גוף כל תו נמשך 0.8 שניות, עם זנב דעיכה מעריכית של 1.4 שניות וחפיפה עדינה של זנב הצליל לתו הבא.
קובץ ההשוואה הוא צילום מצב היסטורי: FluidR3 הקודם מול Salamander שנבחר.
כדי לשחזר את הקבצים החדשים, הריצו `python scripts/prepare-salamander.py` לאחר
הורדת וחילוץ חבילת המקור המפורטת בפרטי הרישוי. מעטפת העוצמה מיושמת בזמן הנגינה,
ולא נאפית בדגימות עצמן, כדי לא להפעיל את הריכוך פעמיים.

## אופן השמעת המרווח

בתפריט הקטן ליד המנעד בוחרים עלייה, ירידה, עלייה ואז ירידה או הרמוני.
עלייה ואז ירידה משמיעה נמוך–גבוה–גבוה–נמוך; הרמוני משמיע את שני התווים בו־זמנית,
בהנמכת עוצמה קלה כדי לא ליצור קפיצה בעוצמה. בשאר האפשרויות נשמר הקצב והפייד־אאוט.
בכל האופנים נשמרים אותם שני גובהי צליל בתוך המנעד. אפשר לענות כשהתו השני מתחיל,
בלי לחכות לזנב הדעיכה. הבחירה נשמרת בדפדפן ומשותפת לתרגול המודרך והחופשי,
להאזנה חוזרת ולהדגמת מרווח חדש. ההתקדמות והסטטיסטיקות הקיימות ממשיכות להצטבר.

## לשמוע ולשיר — שלב ראשון באפליקציה

בראש האפליקציה בוחרים בין „לשמוע ולשיר” לבין „לשיר ולזהות מרווחים”. בשירה מופיע תרגיל אחד בכל פעם: צליל בודד, שני צלילים בעלייה/ירידה, או דו–רה–מי–רה. אפשר לעבור בחופשיות, ללא תנאי פתיחה. אפשר גם לפתוח ישירות את `/singing/`. האבטיפוס ההיסטורי נשאר ב־`/sing-back/`.

השירה משתמשת באותם בקרי זיהוי ופסנתר שנבדקו באבטיפוס. הממשק ב־`public/singing/` כולל ניווט, התאמה לטלפון ושמירת בחירות תחת `ear-training-singing-v1`, בנפרד ממפתחות ההתקדמות והסשן של המרווחים. נשמרים התרגיל, תו ההתחלה בכל תרגיל וכיוון הזוג; הקול אינו נשמר או נשלח לשרת. מעבר בין תרגילים או למסלול המרווחים מפסיק מיקרופון והשמעה, כולל בקשות שעדיין ממתינות לאישור או לטעינת דגימה.

נדרש HTTPS או localhost למיקרופון, עם אישור מפורש בלחיצה. שני התרגילים המתוזמנים מציעים ניסיון חדש ללא דוגמה, עם ספירה קצרה. טווח הדיוק ±25 סנט ואוקטבות שקולות. בתו בודד נדרשות 650ms רצופות; בזוג 600ms מצטברות בכל חלון 1800ms; בחימום 400ms מצטברות בכל חלון 1500ms. אין ציונים מצטברים, נעילות או היסטוריה לשירה.

בדיקה ידנית: פתחו את האתר, בחרו „לשמוע ולשיר”, הפעילו מיקרופון ואשרו. נסו את שלושת התרגילים עם אוזניות, כולל ניסיון חוזר ללא דוגמה. החליפו תו, רעננו וודאו שהבחירה נשמרת. עברו למרווחים וודאו שסמן המיקרופון בדפדפן נכבה וההתקדמות שלכם נשמרה. בקובץ HTML מקומי קיים קישור למסך השירה באתר המאובטח.

## פתיחת שלב שני הצלילים

במסך השירה, השלב הראשון דורש 10 שאלות שהושלמו. חמש הראשונות נבחרות באקראי מתווים טבעיים בלבד; החמש הבאות הן ערבוב אקראי של לבנים ושחורים, עם לפחות תו אחד מכל סוג. התו נקבע מראש לשאלה ואי אפשר לדלג עליו לפני הצלחה. יש להאזין לפני השירה; האזנות וניסיונות חוזרים אינם נספרים כשאלות נוספות. הצלחה אינה חייבת להיות ברצף, ולא משנים את סף ±25 הסנט או את זמן היציבות של התו הבודד.

„הצליל הבא” משמיע את השאלה הבאה. לאחר 10 הצלחות מוצגת הודעה ואפשר לבחור לעבור לשני צלילים. תרגילי ההמשך נעולים עד השלמת השלב הראשון; לא הוגדרו עדיין תנאי השלמה נוספים לשלב השני. פרטי התוכנית, השאלה וההשלמות נשמרים תחת `ear-training-singing-progress-v1`, בנפרד מהעדפות השירה ומכל נתוני המרווחים. רענון שומר גם הצלחה שטרם עברו ממנה לשאלה הבאה, ואינו סופר אותה שוב.

## הכנה קצרה לרצף — שלב שני

אחרי 10 הצלחות בתו בודד נפתח „מתכוננים לשיר רצף”: ארבעה זוגות בלבד — שניים בעלייה ולאחריהם שניים בירידה, בגבהים נוחים שמוגרלים מראש. כל זוג נספר רק כששני הצלילים מצליחים באותו ניסיון. אפשר לנסות שוב ללא הגבלה ובלי דרישה לרצף הצלחות; גם ניסיון ללא דוגמה זמין. זוג שכבר הושלם לא נספר שוב. „הזוג הבא” מופיע לצד פעולות התרגול ונפתח אחרי הצלחה.

אחרי ארבע הצלחות נפתח חימום דו–רה–מי–רה, עם הודעה וכפתור מעבר, ללא מעבר אוטומטי. התרגילים נשארים זמינים לאחר פתיחתם. נתוני הזוגות נשמרים במפתח חדש `ear-training-singing-pairs-v1`, כולל הזוג הנוכחי והצלחה שממתינה למעבר. נתוני השלב הראשון והמרווחים נשמרים ללא שינוי. המיקרופון, הפסנתר, ספי הדיוק והתזמון נשארים כפי שהיו.

## חמש תבניות חימום קבועות

בשלב החימום בוחרים בין חמש תבניות, כולן מדו C3 וללא שינוי תו בסיס: דו–רה–מי–רה; דו–רה–מי–סול; דו–רה–מי–פה–סול–פה–מי–רה–דו; דו–מי–סול–מי–דו; דו–מי–רה–פה–מי–סול–דו (דו האחרון C3, כמו בתחילת התבנית). הבחירה נשמרת לצד העדפות השירה. אפשר לבחור תבנית או לעבור לבאה, להאזין ולנסות שוב ללא דוגמה. אין תנאי פתיחה נוספים בין התבניות.

הרשימה המדויקת נמצאת ב־`public/singing/warmup-patterns.js`. התיבה, הנגינה, הספירה, משך השירה והפירוט לפי תו מתאימים למספר התווים בכל תבנית. הקצב נשאר 1.5 שניות לתו והצלחה דורשת 0.4 שניות מצטברות בטווח ±25 סנט לכל תו. החיווי ממוקם ביחס לתו המטרה הנוכחי כדי להציג נכון גם סול הגבוה ואת דו הנמוך בסיום, עם שמירת השקילות בין אוקטבות.

## פתיחת תבניות החימום לפי הסדר

חמש תבניות החימום נפתחות בהדרגה: בתחילה רק הראשונה זמינה. הצלחה בכל התווים באותו ניסיון פותחת את התבנית הבאה, בלי מעבר אוטומטי. אפשר לחזור לתבניות פתוחות ולנסות שוב ללא הגבלה; הצלחה חוזרת באותה תבנית לא פותחת שלב נוסף. הדגמה, שירה חלקית, עצירה וכישלון לא מקדמים.

ההתקדמות והתבנית הנוכחית נשמרות תחת `ear-training-singing-warmups-v1`, בנפרד מנתוני השלבים הקודמים והמרווחים. בחירה ישנה מתוך התפריט החופשי אינה הוכחת הצלחה ואינה פותחת תבניות; כשאין נתוני השלמה מתחילים בתבנית הראשונה. הקצב, התווים הקבועים בדו וסף הדיוק לא השתנו.

## מסלול מודרך ותרגול חופשי בשירה

ב„לשמוע ולשיר” בוחרים בין שני מצבים. המודרך שומר על עשרת הצלילים, ארבעת הזוגות וחמש התבניות שנפתחות לפי הסדר. ההצלחה בחימום מדגישה מה נפתח ומציגה בתוך הודעת ההצלחה כפתור מעבר ראשי, ללא מעבר אוטומטי. תבניות עתידיות מוצגות כ„בהמשך המסלול”.

בחופשי כל התרגילים והתבניות זמינים: בחירת צליל כרומטי יחיד, גובה וכיוון לזוג, וכל חמש תבניות החימום הקבועות בדו. הצלחות בחופשי אינן משנות אף אחד משלושת מפתחות ההתקדמות המודרכת. המצב, התרגיל והבחירות החופשיות נשמרים בהעדפות `ear-training-singing-v1`; מעבר למודרך משחזר את השאלה והתבנית המודרכות, ומפסיק השמעה ומיקרופון לפני החלפת מצב.

הקישור הראשי של האתר נפתח כברירת מחדל ב„לשמוע ולשיר”. מעבר למרווחים זמין בכפתור השני בראש המסך; נתוני ההתקדמות והסיכום נשמרים ללא שינוי. קובץ ה־HTML המקומי ממשיך לפתוח את תרגול המרווחים, לצד קישור לשירה באתר המאובטח.

## זיהוי אקורדים

בניווט הראשי בחרו **3. זיהוי אקורדים**. האזנה לאקורד משמיעה את כל צליליו יחד; **השמע מפורק** משמיע מהנמוך לגבוה. מזהים את סוג האקורד בלבד. כל האקורדים במצב יסודי, בשורש אקראי C3–B4, מתוך דגימות הפסנתר הקיימות.

המסלול כולל 12 שלבים ו־13 סוגים: מז׳ור ומינור בתחילה, ובהמשך dim, aug, Sus2, Sus4, 7, Maj7, m7, m7♭5, 7♯5, mMaj7, dim7. כל שלב מצטבר, עם אותם כללי חלון, כיסוי ו־80% בניסיון הראשון כמו במרווחים. במסך הסיכום נספרות רק שאלות שהושלמו. תרגול חדש מאפס את הסשן בלבד.

- `src/chords.js`: נוסחאות, בחירת שאלות, התקדמות ואימות שמירה.
- `src/chord-screen.js`: בקר עצמאי וממשק התרגיל; משתמש באותו שמע, סיכום, בדיקת תשובות ועיצוב.
- מפתחות שמירה נפרדים: `ear-training-chords-v1`, `ear-training-chords-session-v1`. שדה `interval` בשאלה ו־`intervals` בסשן מכילים מזהי סוג אקורד כדי להשתמש באותם חישובי תשובות וסיכום. אין כתיבה לנתוני המרווחים או השירה.
- `tests/chords.test.js`, `tests/chords-ui.test.js`: נוסחאות, גבולות שורשים, התקדמות, שגיאה ותיקון, רענון, סיכום והפרדת שמירה. בדיקות השמע כוללות גם תזמון של שלשות ומרובעים.

## הוצאת בס משמיעה

בניווט הראשי בחרו **4. הוצאת בס משמיעה**. האזינו לארבעה אקורדים, נסו לשיר את הבס, וחפשו ארבעה צלילים במקלדת. לחיצה על קליד משמיעה אותו בלבד; כפתור „הכנס למשבצת” מאשר את הצליל לתשובה. אפשר לבחור משבצת כדי לתקן אותה, להשמיע את התשובה, לבדוק ולחשוף פתרון רק לאחר בדיקה. אין זיהוי מיקרופון או פתיחת רמות בתרגיל הזה.

- שש תבניות מוכרות ב־12 סולמות, 72 שילובים. שתי התבניות הנוספות הן C–Em–Am–G (דרגה שלישית) ו־Am–G–F–E (ירידה מינורית עם דרגה שביעית ודרגה חמישית מז׳ורית מהמינור ההרמוני). האקורדים הם שלשות מז׳ור ומינור במצב יסודי. הבס הוא השורש C2–B2, והאקורד באוקטבה שמעליו. מקלדת C2–B3 מאפשרת את כל התשובות; הבדיקה משווה מחלקת גובה, ולכן אוקטבה אחרת נכונה אבל טרנספוזיציה אינה נכונה.
- כל אקורד מתחיל במרווח קבוע של 1.6 שניות; צלילו דועך בעדינות אל הבא. אותו תכנון שמע משמש למהלך המלא ולבס בלבד. הבס משתמש בדגימות Salamander הקיימות אוקטבה אחת נמוך יותר באמצעות קצב נגינה 0.5, ללא קבצי סאונד נוספים. מעטפות המרווחים והאקורדים הקיימים נשארות ללא שינוי.
- `src/bass.js`: מאגר המהלכים, נוסחאות, בדיקה ושמירה. `src/bass-screen.js`: הבקר והממשק. `src/audio.js`: תזמון הדגימות המשותף.
- שמירה נפרדת ב־`ear-training-bass-v1`: השאלה והתשובה הנוכחיות, ניסיונות, שימוש בעזרה, חשיפת פתרון ונתונים מצטברים. ניסיון ראשון פירושו ההגשה הראשונה; השמעה חוזרת אינה ניסיון. מעבר לתרגיל הבא רושם את המהלך פעם אחת, גם אם זוהו רק חלק מהצלילים. שימוש בעזרת בס בלבד נרשם גם אם נעשה לאחר בדיקה.
- `tests/bass.test.js`, `tests/bass-ui.test.js` ובדיקות השמע בודקים את כל הסולמות, התאמת הבס, תיקון, אוקטבות, טרנספוזיציה שגויה, רענון, עזרה, ניווט וביטול שמע. במובייל ניתן לגלול את המקלדת אופקית; העמוד עצמו אינו דורש גלילה אופקית.

### מסלול מודרך ותרגול חופשי בבס

מסך הבס כולל בחירה בין מסלול מודרך לתרגול חופשי. המסלול המודרך כולל עשרה שילובים שונים, עם איזון בין שש התבניות ועשרה סולמות שונים. אין חובת הצלחה בניסיון ראשון: כל מהלך נספר ברגע שנבדקו נכון כל ארבעת הצלילים, גם אחרי תיקונים ובעזרת בס בלבד. אי אפשר לדלג על מהלך שלא נפתר. ההצלחה נשמרת מיד, ללא צורך בלחיצה על המהלך הבא, ואינה נספרת פעמיים ברענון. לאחר העשירי מוצגת הודעת השלמה ואפשר לעבור לתרגול החופשי.

המסלול נשמר ב־`ear-training-bass-guided-v1`, והמצב הנבחר ב־`ear-training-bass-mode-v1`. התרגול החופשי ממשיך להשתמש ב־`ear-training-bass-v1`, כך שנתוני התרגול מהגרסה הקודמת נשמרים בו. לשני המצבים שאלות ותשובות עצמאיות; מעבר ביניהם אינו מאפס או מקדם את האחר. `src/bass-course.js` מנהל את יצירת סדרת השאלות ואימות השמירה.

## הוצאת מהלך אקורדים משמיעה — רמה 1

הכניסה **5. הוצאת מהלך אקורדים משמיעה** נמצאת אחרי תרגיל הבס ופתוחה ללא תלות בהשלמת תרגילים אחרים. זהו תרגיל עצמאי ללא מגבלת שאלות:

1. מוצאים את ארבעת צלילי הבס בעזרת אותה מקלדת האזנה והזנה. אפשר לשמוע את המהלך, את הבס בלבד ואת רצף התשובה. רק ארבעה צלילים נכונים פותחים את השלב הבא; אוקטבה אחרת מתקבלת, טרנספוזיציה אינה מתקבלת.
2. בוחרים מז׳ור או מינור ליד כל בס שנמצא. אפשר לשמוע את המקור, כל אקורד מקורי בנפרד, ואת המהלך שנבנה בבחירות התלמיד. משוב לכל אקורד מאפשר לתקן ללא חשיפת התשובה. הצלחה מלאה מציגה את שמות האקורדים, השמעה וכפתור מהלך חדש.

אותו מהלך נשמר בשני השלבים. התזמון, הבס, העוצמות והפסנתר משותפים למקור ולמהלך התלמיד; בחירה במז׳ור/מינור משנה רק את הטרצה. האקורדים הבודדים מופקים מאותו תכנון שמע של המהלך המלא. מחולל 72 המהלכים, בדיקת הבס וניגון הפסנתר משותפים לתרגיל הבס הקיים. `src/bass-keyboard.js` משתף רק את תצוגת המקלדת, ללא שינוי בהתנהגות או בשמירה של הבס.

`src/progression.js` מנהל לוגיקה ושמירה, ו־`src/progression-screen.js` מנהל את המסך. המפתח `ear-training-chord-progression-v1` שומר את שני שלבי השאלה הנוכחית, הבחירות, הניסיונות, השימוש בעזרת בס ואת מספר המהלכים שנפתרו. מדדי הצלחה בהגשה ראשונה נספרים רק עבור מהלכים שהושלמו במלואם, פעם אחת. רענון או השמעה חוזרת אינם מוסיפים ניסיון. נתוני הבס, האקורדים, המרווחים והשירה נשמרים בנפרד.

בדיקות: `tests/progression.test.js` בודק את כל 72 השילובים והצלילים בכל השמעה; `tests/progression-ui.test.js` בודק את שני השלבים מתחילתם ועד סופם, תיקון טעויות, האזנה ללא הזנה, רענון, עצירה, מהלך חדש, ניווט והפרדת שמירה.

### מסלול מודרך בהוצאת מהלך אקורדים

התרגיל כולל כעת **מסלול מודרך של 10 מהלכים** ו**תרגול חופשי ללא הגבלה**. בחירות סוג האקורד מוצגות בעברית ובאנגלית — מז׳ור / Major ומינור / Minor — עם אותם שמות שמשמשים בזיהוי האקורדים.

המסלול משתמש באותו מחולל סדרה מאוזנת של תרגיל הבס: עשרה שילובים שונים, עם פיזור בין שש התבניות וסולמות שונים. מהלך נספר רק לאחר פתרון שני החלקים, בס ואקורדים, גם עם עזרה ותיקונים. בסיום העשירי מוצגת הודעת השלמה; אין מעבר אוטומטי לתרגיל אחר.

שמירת המסלול: `ear-training-chord-progression-guided-v1`; המצב הנבחר: `ear-training-chord-progression-mode-v1`. התרגול החופשי ממשיך להשתמש ב־`ear-training-chord-progression-v1`, כך שגם שאלה ותשובות מהגרסה הקודמת נשמרות בו. מעבר מצב ורענון שומרים על שני התרגולים בנפרד. ברירת המחדל למשתמש שטרם בחר מצב היא המסלול המודרך. `src/progression-course.js` מנהל את הסדרה ואימות ההתקדמות. הבדיקות כוללות מסלול שלם של עשרה מהלכים, טעויות בשני החלקים, עזרה, השמעה חוזרת, רענון ומעבר בין המצבים.

בתבנית החימום **דו–רה–מי–פה–סול–פה–מי–רה–דו** בלבד, טווח הדיוק הוא ±40 סנט. טווח זה משותף לחישוב ההצלחה, לצבע הנקודות ולרוחב האזור הירוק. זמן התו נשאר 1.8 שניות וזמן הדיוק המצטבר הנדרש נשאר 0.4 שניות. יתר תרגילי השירה והתבניות נשארים ב־±25 סנט; מעבר תבנית מחזיר את הסף המתאים. ההגדרה בתבנית עצמה, ללא שינוי בנתוני ההתקדמות השמורים.

## שלב 6 — הוצאת שירים משמיעה

פתחו **6. הוצאת שירים משמיעה**, בחרו שיר בספרייה ואז חלק בשיר. בחירת חלק קופצת לתחילתו. הנגן מאפשר ניגון/השהיה, עצירה וחזרה לתחילת החלק, גרירה לכל זמן, דילוג ±5 שניות, מהירויות 0.5× / 0.75× / 1×, וסימון התחלה/סיום ללופ (בהקלדה או לפי הזמן הנוכחי). האטה משתמשת ב־HTML Audio עם `preservesPitch` ובמקבילות הדפדפנים לשמירת הגובה. איכות מתיחת הזמן תלויה בדפדפן. הלופ נבדק בכל פריים ובאירועי זמן, ואינו לופ מדויק ברמת דגימה.

בשלב הראשון מוצאים את הבס בעזרת המקלדת המשותפת, מאזינים לתשובה, בודקים ומתקנים. רק רצף מדויק של מחלקות גובה פותח את בחירת מז׳ור / Major ומינור / Minor. אין כפתור בס בלבד ואין הפרדת ערוצים. בשלב השני אפשר לנגן את המהלך שנבנה בפסנתר, בקצב התואם למהירות הנגן, ולהשוות להקלטה. השמעת תשובה משהה את ההקלטה; השמעת ההקלטה עוצרת את הפסנתר כדי שלא יתנגשו.

הדוגמה היחידה היא **„צעד ראשון”**, קטע מקורי של דקה עם פסנתר Salamander, בס ותופים סינתטיים. המהלך C–G–Am–F חוזר שש פעמים ב־96 BPM. „בית” הוא 0–30 שניות ו„פזמון” 30–60; בכל חלק מזינים את ארבעת אקורדי המהלך החוזר פעם אחת. הקובץ האמיתי נמצא ב־`public/songs/first-light.mp3` (כ־1.2 MB) ומוגש מהאתר; אין יצירת הקלטה בזמן הטעינה ואין תלות בשירות חיצוני. `public/songs/LICENSE.md` כולל קרדיטים. הסקריפט `scripts/render-demo-song.py` יוצר אותו מנתוני הקטלוג עם numpy ו־ffmpeg; אין צורך בכלים האלה להרצת האפליקציה. בקובץ HTML מקומי ההקלטה נטענת מהאתר ולכן דורשת חיבור, בעוד דגימות הפסנתר הקיימות נשארות כלולות בקובץ.

### החלפת הדוגמה או הוספת שיר אמיתי

1. שמרו MP3 ב־`public/songs/`, למשל `my-song.mp3`.
2. עדכנו או הוסיפו רשומה ב־`src/songs/catalog.json`: מזהה קבוע, שם, אמן, קושי, נתיב `songs/my-song.mp3`, משך בשניות ו־BPM.
3. הגדירו רק את חלקי השיר הרצויים: מזהה, שם, התחלה וסיום בשניות, מספר פעימות לכל אקורד ורצף האקורדים הנכון. כל אקורד מוגדר עם `root` במספר MIDI, `quality` מסוג `major` או `minor`, וכתיב שורש `english` ו־`hebrew` המתאים לסולם. השם באנגלית הוא השורש בלבד, בלי m; האפליקציה מוסיפה אותו למינור בתוצאה.
4. הריצו `npm test`, `npm run test:ui` ו־`npm run test:standalone`, ופרסמו כרגיל. אין שינוי בקוד הממשק ואין מערכת ניהול. כדי לשמור על השלמות קיימות, השאירו מזהי שיר וחלק קבועים; עבור תוכן חדש השתמשו במזהים חדשים.

הגרסה הנוכחית תומכת בשלשות מז׳ור/מינור ובמהירות קבועה לשיר עם משך אחיד לאקורד בתשובת הפסנתר. זו הקלטת בדיקה מתוכנתת, לא ביצוע חי או שיר מסחרי. להקלטה עם שינויי קצב או משכי אקורדים לא אחידים יהיה צורך להרחיב את נתוני התזמון.

`src/songs.js` מנהל נתונים, תשובות ואימות שמירה; `src/song-player.js` מנהל HTML Audio ולופים; `src/song-screen.js` מציג ספרייה ותרגול. ההתקדמות ב־`ear-training-songs-v1` נפרדת לכל שיר וחלק. שאלה חלקית נשמרת ברענון, והשלמה נשמרת גם כשבוחרים לתרגל את החלק מחדש. בדיקות יחידה וממשק מכסות בחירת שיר וחלק, שמע ותזמון התשובה, בדיקה ותיקון בשני השלבים, רענון, הפרדת נתונים, מהירויות, דילוגים, לופים והעתקת MP3 לפרסום. בדיקת Chromium נוספת מאמתת ניגון MP3 אמיתי, אנרגיית שמע, לופ בהאטה, שני שלבי התרגיל ותצוגה ברוחב טלפון.

שאר הרשומה נשארת באותו מבנה: `id`, `title`, `artist`, `difficulty`, `description`, `duration`, `bpm` ו־`parts`. יש להזין זמני חלקים ואקורדים **מאומתים של אותו סרטון**. ב־YouTube אפשר להשמיט `duration` ולקבל את משך הסרטון מהנגן; עד הטעינה טווח החיפוש מכסה את החלקים שהוגדרו. אם קצב השיר אינו ידוע, משמיטים גם `bpm` וגם `beatsPerChord`: הדגמת התשובה בפסנתר מתנגנת אז בקצב ניטרלי של שתי שניות לאקורד (ובהתאם למהירות הנבחרת), עם הסבר בממשק. אין טענה שההדגמה מסונכרנת לקצב ההקלטה. שיר MP3 קיים אינו דורש שינוי; אפשר גם להגדיר `source: { "type": "audio", "src": "songs/first-light.mp3" }`.

הנגן משתמש רק ב־[YouTube IFrame Player API הרשמי](https://developers.google.com/youtube/iframe_api_reference), נטען רק בעת פתיחת שיר YouTube, ומציג את הסרטון והפקדים המקוריים בגודל מינימלי 200×200. אין חילוץ, הורדה או אחסון של שמע YouTube. יש לפתוח ב־HTTPS או localhost עם Referer תקין; קובץ HTML מקומי מציג הסבר במקום לנסות לעקוף את זיהוי האתר.

הפקדים המשותפים משמשים לניגון/השהיה, דילוג, גרירה, בחירת חלק ולופ. ההאטות הזמינות נקבעות על ידי הסרטון; אפשרות שאינה נתמכת מושבתת והמהירות המוצגת מתקבלת מהנגן בפועל. לופ נבדק בכל 100 מילישניות ובאירועי זמן, ויכול לסטות עקב buffering ונקודות החיפוש של YouTube. אין הבטחה ללופ מדויק. חסימת autoplay מפנה ללחיצה בנגן המקורי. שגיאות טעינה, הסרה/פרטיות, חסימת הטמעה וזיהוי אתר מוצגות בעברית, לצד ניסיון טעינה מחדש וקישור לסרטון. מגבלות מדינה עשויות להופיע כשגיאת זמינות כללית.

נגן YouTube נשאר מחובר למסמך בעת בחירת קלידים, תשובות וחלקים; היציאה מהתרגיל משמידה אותו ועוצרת השמעה. הצלחה מוצגת בתוך המסך ולא בחלונית שמסתירה את הסרטון. שמירת התשובות נשארת באותו מפתח ומבנה קיימים, בלי מחיקת התקדמות.

בדיקות YouTube משתמשות בנגן API מדומה: שליטה, זמני חלקים, קצב, לופ, שגיאות, ניסיון חוזר, שימור iframe, שני שלבי התרגול ושמירת השלמה. בסביבת הפיתוח החיבור הישיר ל־YouTube מחזיר 403 מחומת הרשת, ולכן ניגון YouTube חי לא אומת כאן. אחרי הוספת שיר מאומת, יש לבדוק אותו באתר המפורסם במחשב ובטלפון, כולל הרשאת הטמעה, שמע, האטה ולופ. בדיקות MP3 והתרגילים הקיימים ממשיכות לרוץ בנפרד.

בספרייה נוסף **„ככה וככה” — שלום חנוך**, סרטון `kKTyqRlBNJI`. לפי המידע שסופק: „פתיח ובית” 0:04–1:26 — Em ואז C; „פזמון” 1:27–2:17 — Am ואז Em. בכל חלק מזינים את שני האקורדים פעם אחת לפי הסדר. התשובות אינן מוצגות לפני הפתרון. המשך וה־BPM המלאים לא הומצאו; משך ההקלטה מגיע מה־API והדגמת התשובה משתמשת בקצב ניטרלי. בדיקות הממשק מכסות שני חלקים אלה, טעויות ותיקון, זמני מעבר, השלמה ורענון, בנפרד מקטע ה־MP3 הקיים. ניגון חי של הסרטון עדיין טעון בדיקה באתר בגלל חסימת YouTube בסביבת הפיתוח.

כותרת גדולה מציגה את שם החלק הפעיל ומיקומו בשיר. לאחר פתרון נכון של הבס ושל סוגי האקורדים, נשמרת ההשלמה, ההשמעה מושהית ומופיעה חלונית הצלחה עם שם החלק שהושלם ושם החלק הבא לפי סדר הקטלוג. החלונית מקבלת מיקוד ומובאת למסך אוטומטית; היא נמצאת בזרימת העמוד כדי לא לכסות את נגן YouTube. כפתור „ממשיכים ל…” פותח את החלק הבא וממקם את הנגן בתחילתו. אפשר גם להישאר בחלק הנוכחי או לחזור אליו בהמשך, וכפתור המעבר נשאר גם במסך ההשלמה. תשובה שגויה או הצלחה בבס בלבד אינן פותחות את החלונית. בחלק האחרון מוצג סיום השיר ללא הבטחה לחלק נוסף.
