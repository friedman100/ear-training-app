# אוזן מוזיקלית — האקדמיה לגיטרה

אפליקציית Web בעברית וב־RTL לתרגול מרווחים מלודיים עולים, עם פסנתר בלבד. ללא שרת, הרשמה או תשלום.

## לפתוח ולהתחיל לתרגל

הדרך הפשוטה: פתחו את `ear-training.html` שנוצר באמצעות `npm run standalone` מתוך תיקיית `dist`, בדפדפן Chrome, Edge, Firefox או Safari. כל דגימות הפסנתר כלולות בקובץ. לחצו על **האזנה למרווח** ואפשרו צליל במכשיר. השמעה מתחילה רק בלחיצה, בהתאם לכללי הדפדפנים.

בטלפון מומלץ לפתוח את הגרסה המתארחת באתר HTTPS. פתיחת קובצי HTML מקומיים בטלפון משתנה בין דפדפנים. בחלון גלישה פרטי ההתקדמות עשויה להימחק בסגירתו.

## הרצה לפיתוח / תצוגה מקדימה

נדרש Node.js 20.19 ומעלה או 22.12 ומעלה.

```sh
npm ci
npm run dev
```

פתחו את הכתובת שמופיעה במסוף (בדרך כלל `http://localhost:5173`). בסביבה מרוחקת פתחו תצוגה מקדימה לפורט 5173; localhost של הסביבה אינו ה־localhost של המחשב שלכם.

```sh
npm test
npm run test:ui
npm run build
npm run standalone
```

`dist` מתאים לכל שירות אחסון סטטי. אין צורך במסד נתונים או במפתחות API. ההתקדמות נשמרת בדפדפן ובכתובת שבה מתרגלים; מעבר בין דומיינים/דפדפנים או ניקוי נתוני האתר אינם מעבירים את ההתקדמות.

## כללי התרגול

- 0.6 שניות לכל צליל ו־0.05 שניות שקט ביניהם. תווים מקוריים בדגימות פסנתר FluidR3 GM, בכיוון שווה־מזג A4=440Hz. פרטי רישוי ב־`public/audio/LICENSE.md`.
- מנעדים: נמוך C3–C5, אמצעי C4–C6, גבוה C5–C7. שני הצלילים תמיד בתוך המנעד.
- תשובה שגויה מסומנת באדום בלבד. אפשר לנסות עד שמצליחים; אין מעבר אוטומטי.
- רק התשובה הראשונה לשאלה נרשמת במדדים. טעויות נוספות והאזנות אינן משנות אותם.
- חלון ההתקדמות הוא `max(20, 4 × מספר המרווחים הפעילים)` שאלות. נדרשים 80% הצלחה לפחות ולפחות שתי הופעות לכל מרווח. הבחירה מאזנת את מספר הופעות המרווחים, עם צליל התחלה אקראי בכל שאלה. החלון מתאפס בפתיחת שלב.
- חלק א׳ מסתיים בסקונדה קטנה. המעבר לחלק ב׳ נעשה רק בלחיצה.
- מסלול מודרך ומצב חופשי שומרים מדדים נפרדים. הגדרות המנעד משותפות.
- שאלת התרגול עצמה מתחדשת בטעינה; ההתקדמות, המדדים וההגדרות נשמרים.

## מבנה הקוד

- `src/logic.js`: מרווחים, מנעדים, שאלות, בדיקת תשובות, פתיחת שלבים וטעינת התקדמות.
- `src/audio.js`: טעינת דגימות ותזמון Web Audio.
- `src/main.js`: ממשק וניהול התרגול.
- `src/style.css`: עיצוב רספונסיבי.
- `tests`: בדיקות לוגיקה ואינטראקציה בממשק.
- `scripts/standalone.mjs`: אריזת האפליקציה לקובץ HTML עצמאי.

בדיקות הממשק רצות בסביבת DOM מדומה; הן אינן מחליפות בדיקת האזנה פיזית או בדיקה בדפדפן ובטלפון אמיתיים.
