# אוזן מוזיקלית — האקדמיה לגיטרה

אפליקציית Web בעברית וב־RTL לתרגול מרווחים מלודיים עולים, עם פסנתר בלבד. ללא שרת, הרשמה או תשלום.

## לפתוח ולהתחיל לתרגל

הדרך הפשוטה: פתחו את `ear-training.html` שנוצר באמצעות `npm run standalone` מתוך תיקיית `dist`, בדפדפן Chrome, Edge, Firefox או Safari. כל דגימות הפסנתר כלולות בקובץ. לחצו על **האזנה למרווח** ואפשרו צליל במכשיר. השמעה מתחילה רק בלחיצה, בהתאם לכללי הדפדפנים.

בטלפון מומלץ לפתוח את הגרסה המתארחת באתר HTTPS. פתיחת קובצי HTML מקומיים בטלפון משתנה בין דפדפנים. בחלון גלישה פרטי ההתקדמות עשויה להימחק בסגירתו.

## הרצה לפיתוח / תצוגה מקדימה

נדרש Node.js 20.19 ומעלה או 22.12 ומעלה.

```sh
npm ci
npm run dev
```

פתחו את הכתובת שמופיעה במסוף (בדרך כלל `http://localhost:5173`). בסביבה מרוחקת פתחו תצוגה מקדימה לפורט 5173; localhost של הסביבה אינו ה־localhost של המחשב שלכם.

```sh
npm test
npm run test:ui
npm run build
npm run standalone
```

`dist` מתאים לכל שירות אחסון סטטי. אין צורך במסד נתונים או במפתחות API. ההתקדמות נשמרת בדפדפן ובכתובת שבה מתרגלים; מעבר בין דומיינים/דפדפנים או ניקוי נתוני האתר אינם מעבירים את ההתקדמות.

## כללי התרגול

- גוף הצליל נמשך 0.8 שניות, עם זנב דעיכה מעריכית של 1.4 שניות. התו השני מתחיל לאחר 0.85 שניות, כך שזנב הראשון חופף לו בעדינות עד לשקט. תווים מקוריים בדגימות פסנתר Salamander Grand Piano V3 (שכבת נגינה עדינה 4 מתוך 16), בכיוון שווה־מזג A4=440Hz. פרטי רישוי ב־`public/audio/LICENSE.md`.
- מנעדים: נמוך C3–C5, אמצעי C4–C6, גבוה C5–C7. שני הצלילים תמיד בתוך המנעד.
- תשובה שגויה מסומנת באדום בלבד. אפשר לנסות עד שמצליחים; אין מעבר אוטומטי.
- רק התשובה הראשונה לשאלה נרשמת במדדים. טעויות נוספות והאזנות אינן משנות אותם.
- חלון ההתקדמות הוא `max(20, 4 × מספר המרווחים הפעילים)` שאלות. נדרשים 80% הצלחה לפחות ולפחות שתי הופעות לכל מרווח. הבחירה מאזנת את מספר הופעות המרווחים, עם צליל התחלה אקראי בכל שאלה. החלון מתאפס בפתיחת שלב.
- חלק א׳ מסתיים בסקונדה קטנה. המעבר לחלק ב׳ נעשה רק בלחיצה.
- מסלול מודרך ומצב חופשי שומרים מדדים נפרדים. הגדרות המנעד משותפות.
- שאלת התרגול הנוכחית, כולל מספר הניסיונות, נשמרת בטעינה מחדש. יש ללחוץ שוב על האזנה לאחר רענון לפני בחירת תשובה.

## מבנה הקוד

- `src/logic.js`: מרווחים, מנעדים, שאלות, בדיקת תשובות, פתיחת שלבים וטעינת התקדמות.
- `src/audio.js`: טעינת דגימות ותזמון Web Audio.
- `src/main.js`: ממשק וניהול התרגול.
- `src/style.css`: עיצוב רספונסיבי.
- `tests`: בדיקות לוגיקה ואינטראקציה בממשק.
- `scripts/standalone.mjs`: אריזת האפליקציה לקובץ HTML עצמאי.

בדיקות הממשק רצות בסביבת DOM מדומה; הן אינן מחליפות בדיקת האזנה פיזית או בדיקה בדפדפן ובטלפון אמיתיים.

## סיום תרגול וסיכום אישי

לחצו על **סיום תרגול** בחלק העליון של כרטיס התרגול. הסיכום מתייחס לתרגול הנוכחי בשני המצבים יחד, וסופר רק שאלות שהושלמו בהצלחה — כל שאלה פעם אחת. טעות ואחריה תיקון נכללים בשאלה שהושלמה, אך אינם הצלחה בניסיון הראשון. האזנות ושאלות שלא הושלמו אינן נספרות בסיכום.

הסיכום כולל מספר שאלות שהושלמו, אחוז הצלחה בניסיון הראשון, רצף מרבי, פירוט הצלחות מתוך שאלות לכל מרווח ומרווחים שנפתחו במסלול המודרך. **תרגול חדש** מאפס רק את נתוני התרגול הנוכחי. אין סיום אוטומטי או מגבלת שאלות.

נתוני התרגול נשמרים במפתח נפרד `ear-training-session-v1`, לצד ההתקדמות הקיימת ב־`ear-training-v1`. רענון משחזר גם סיכום שכבר נפתח. לא נשמרת היסטוריית תרגולים.

## השוואת פסנתרים לפני החלפת מקור הצליל

`demo/piano-comparison.html` הוא קובץ עצמאי להשוואת FluidR3 הקיים מול Salamander Grand Piano V3 בשכבת נגינה עדינה (4 מתוך 16). הורידו ופתחו בדפדפן, בחרו אזור ומרווח ולחצו על כל אחד משני הפסנתרים. אין שינוי בצליל התרגול ואין שימוש בנתוני ההתקדמות.

הקובץ כולל 16 תווים בכל מקור, 5 מרווחים ושלושה אזורי מקלדת. עוצמת המקורות מאוזנת בקירוב לצורך ההשוואה; אין זו מדידת שוויון עוצמה תפיסתית. שני המקורות קוצרו ל־0.8 שניות עם 15ms התחלה רכה ו־300ms דעיכה; נשמרת הפסקה של 50ms בין התווים. לא נעשה שימוש בצלילים של Toned Ear.

- `npm run comparison`: אריזת ההשוואה העצמאית מתוך הקבצים הקיימים.
- `npm run test:comparison`: בדיקת הקובץ העצמאי, כל אפשרויות ההשמעה, חזרה ושמירת נתוני התרגול ללא שינוי.
- `scripts/prepare-piano-comparison.py`: שחזור קובצי ההשוואה. נדרש ffmpeg וחילוץ `audio` מחבילת `@audio-samples/piano-velocity4@1.0.5` לתוך `work/piano-comparison/source`. אין צורך להתקין זאת כדי להשתמש בקובץ המוכן.
- פרטי המקור, הרישוי והעיבוד: `public/piano-comparison/LICENSE.md`.

## הפסנתר שנבחר לתרגול

לאחר השוואת האזנה נבחר Salamander Grand Piano V3, בשכבת נגינה עדינה 4.
כל 49 התווים C3–C7 כלולים מקומית. גוף כל תו נמשך 0.8 שניות, עם זנב דעיכה מעריכית של 1.4 שניות וחפיפה עדינה של זנב הצליל לתו הבא.
קובץ ההשוואה הוא צילום מצב היסטורי: FluidR3 הקודם מול Salamander שנבחר.
כדי לשחזר את הקבצים החדשים, הריצו `python scripts/prepare-salamander.py` לאחר
הורדת וחילוץ חבילת המקור המפורטת בפרטי הרישוי. מעטפת העוצמה מיושמת בזמן הנגינה,
ולא נאפית בדגימות עצמן, כדי לא להפעיל את הריכוך פעמיים.

## אופן השמעת המרווח

בתפריט הקטן ליד המנעד בוחרים עלייה, ירידה, עלייה ואז ירידה או הרמוני.
עלייה ואז ירידה משמיעה נמוך–גבוה–גבוה–נמוך; הרמוני משמיע את שני התווים בו־זמנית,
בהנמכת עוצמה קלה כדי לא ליצור קפיצה בעוצמה. בשאר האפשרויות נשמר הקצב והפייד־אאוט.
בכל האופנים נשמרים אותם שני גובהי צליל בתוך המנעד. אפשר לענות כשהתו השני מתחיל,
בלי לחכות לזנב הדעיכה. הבחירה נשמרת בדפדפן ומשותפת לתרגול המודרך והחופשי,
להאזנה חוזרת ולהדגמת מרווח חדש. ההתקדמות והסטטיסטיקות הקיימות ממשיכות להצטבר.

## לשמוע ולשיר — שלב ראשון באפליקציה

בראש האפליקציה בוחרים בין „לשמוע ולשיר” לבין „לשיר ולזהות מרווחים”. בשירה מופיע תרגיל אחד בכל פעם: צליל בודד, שני צלילים בעלייה/ירידה, או דו–רה–מי–רה. אפשר לעבור בחופשיות, ללא תנאי פתיחה. אפשר גם לפתוח ישירות את `/singing/`. האבטיפוס ההיסטורי נשאר ב־`/sing-back/`.

השירה משתמשת באותם בקרי זיהוי ופסנתר שנבדקו באבטיפוס. הממשק ב־`public/singing/` כולל ניווט, התאמה לטלפון ושמירת בחירות תחת `ear-training-singing-v1`, בנפרד ממפתחות ההתקדמות והסשן של המרווחים. נשמרים התרגיל, תו ההתחלה בכל תרגיל וכיוון הזוג; הקול אינו נשמר או נשלח לשרת. מעבר בין תרגילים או למסלול המרווחים מפסיק מיקרופון והשמעה, כולל בקשות שעדיין ממתינות לאישור או לטעינת דגימה.

נדרש HTTPS או localhost למיקרופון, עם אישור מפורש בלחיצה. שני התרגילים המתוזמנים מציעים ניסיון חדש ללא דוגמה, עם ספירה קצרה. טווח הדיוק ±25 סנט ואוקטבות שקולות. בתו בודד נדרשות 650ms רצופות; בזוג 600ms מצטברות בכל חלון 1800ms; בחימום 400ms מצטברות בכל חלון 1500ms. אין ציונים מצטברים, נעילות או היסטוריה לשירה.

בדיקה ידנית: פתחו את האתר, בחרו „לשמוע ולשיר”, הפעילו מיקרופון ואשרו. נסו את שלושת התרגילים עם אוזניות, כולל ניסיון חוזר ללא דוגמה. החליפו תו, רעננו וודאו שהבחירה נשמרת. עברו למרווחים וודאו שסמן המיקרופון בדפדפן נכבה וההתקדמות שלכם נשמרה. בקובץ HTML מקומי קיים קישור למסך השירה באתר המאובטח.

## פתיחת שלב שני הצלילים

במסך השירה, השלב הראשון דורש 10 שאלות שהושלמו. חמש הראשונות נבחרות באקראי מתווים טבעיים בלבד; החמש הבאות הן ערבוב אקראי של לבנים ושחורים, עם לפחות תו אחד מכל סוג. התו נקבע מראש לשאלה ואי אפשר לדלג עליו לפני הצלחה. יש להאזין לפני השירה; האזנות וניסיונות חוזרים אינם נספרים כשאלות נוספות. הצלחה אינה חייבת להיות ברצף, ולא משנים את סף ±25 הסנט או את זמן היציבות של התו הבודד.

„הצליל הבא” משמיע את השאלה הבאה. לאחר 10 הצלחות מוצגת הודעה ואפשר לבחור לעבור לשני צלילים. תרגילי ההמשך נעולים עד השלמת השלב הראשון; לא הוגדרו עדיין תנאי השלמה נוספים לשלב השני. פרטי התוכנית, השאלה וההשלמות נשמרים תחת `ear-training-singing-progress-v1`, בנפרד מהעדפות השירה ומכל נתוני המרווחים. רענון שומר גם הצלחה שטרם עברו ממנה לשאלה הבאה, ואינו סופר אותה שוב.
