# First Light / צעד ראשון

Original demonstration arrangement generated for Amir Friedman's Guitar Academy.
This is a purpose-made test recording, not a recording of an existing song.

Composition, synthesized percussion and rendering script: generated for this project.
Piano and bass use Salamander Grand Piano V3 samples by Alexander Holm, licensed
under Creative Commons Attribution 3.0: https://creativecommons.org/licenses/by/3.0/
Original sample credits and processing details: ../audio/LICENSE.md

The resulting demo recording is distributed under CC BY 3.0 with the above attribution.
Regenerate using `python3 scripts/render-demo-song.py` (numpy and ffmpeg required).
The application itself needs neither Python nor ffmpeg: it streams the committed MP3.
