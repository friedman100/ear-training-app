# שירת צלילי אקורד — מעבדה נפרדת
מז׳ור, מינור, מוקטן ומוגדל במצב יסודי, שורש אקראי בתוך המנעד שנבחר. שלוש מטרות בסדר נמוך–אמצעי–גבוה; אישור משתמש בין המטרות. ±40 סנט למשך 500ms עם זיהוי אמיתי מהמיקרופון, החלקה ושקילות אוקטבות. אין שמירת התקדמות או שינוי במסלול המרווחים.

בדיקות: `node tests/chord-lab.test.js`, `node tests/harmonic-lab.test.js`, `node tests/audio.test.js`.
בנייה: `vite build --config vite.lab.config.js --base ./`.
שני קובצי הכניסה נבנים אל dist-lab/lab. בפרסום למעבדה, מסך המרווחים מועתק לשורש, מסך האקורדים אל chords/index.html; נתיבי assets וקישורי הניווט מותאמים למיקומם. קובצי assets משותפים ודגימות audio נשמרים בשורש המעבדה. לא לפרסם את כל dist-lab מעל מאגר הבדיקה, כדי לשמר את דפי melodies ו־ani-review הקיימים.
