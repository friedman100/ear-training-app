# מעבדת הפרדת צלילים

ענף ניסוי בלבד: `lab/harmonic-separation`. אין למזג ל־main או להריץ פרסום Pages של האתר הפעיל.

## הפעלה מקומית

`npm ci` ואז `npx vite --config vite.lab.config.js --host 0.0.0.0`.
פתחו `http://localhost:5173/lab/harmonic-separation/` (או הפורט שמופיע במסוף).
localhost מאפשר הרשאת מיקרופון. כתובת IP מקומית ב־HTTP בדרך כלל לא מאפשרת מיקרופון בטלפון.

## בנייה ובדיקות

`npx vite build --config vite.lab.config.js`
`node tests/harmonic-lab.test.js`

## כתובת ניסוי נפרדת

ב־Cloudflare Pages צרו פרויקט חדש, נפרד מהאתר הפעיל, במצב Direct Upload. העלו את קובץ ה־ZIP של תיקיית dist-lab. מתקבלת כתובת HTTPS נפרדת. אין לשנות את הגדרות GitHub Pages במאגר.

לפריסה אוטומטית עתידית: חברו פרויקט Pages חדש לענף `lab/harmonic-separation`, פקודת בנייה `npx vite build --config vite.lab.config.js`, תיקיית פלט `dist-lab`. אין לחבר ל־main.

## בדיקה ידנית

בחרו מרווח, השמיעו יחד, גבוה בלבד, נמוך בלבד ורצף גבוה–נמוך. בדקו שכל לחיצה מחליפה את ההשמעה הקודמת. הפעילו מיקרופון באישור מפורש; שירו את הגבוה ואת הנמוך. בזמן הנגינה ובדעיכה אין זיהוי. בדקו תו באוקטבה אחרת: שמו האמיתי מוצג, ולצדו הסבר על התאמה באוקטבה אחרת. בדקו סירוב הרשאה, שקט, אוזניות ורמקולים. עברו בשלושת השלבים גם בלי הצלחה ובחרו זוג חדש. במצב חופשי לא מופיעים שלבים.

הגדרות ניסוי ב־logic.js: ±40 סנט, יציבות 500ms, המתנה 450ms אחרי זנב הפסנתר. לא נשמרות הקלטות או התקדמות. זיהוי דיבור/רעש אינו מושלם; מדד המחזוריות אינו הוכחה שמדובר בשירה. קו השירה מוגבל בגבולות הגרף אם שרים מחוץ למנעד המוצג; שם התו והאוקטבה נשארים אמיתיים. מומלץ לבחור מנעד המתאים לקול.

הפסנתר וזיהוי הגובה מיובאים מהרכיבים הקיימים ללא שינוי בהם. ארטיפקט הבנייה כולל דגימות פסנתר וייחוס הרישיון הקיים. האתר הפעיל אינו מקשר למעבדה ואינו משתמש בקוד שלה.
